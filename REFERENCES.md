# Обзор источников и аналогов

Дата актуализации: 09.03.2026

Документ фиксирует внешние источники, использованные для анализа рынка, проектирования минимально жизнеспособного продукта и выбора технических решений.

## 1) Цель обзора
- Понять, какие сценарии уже востребованы в Telegram-ботах с эзотерическим или развлекательным позиционированием.
- Посмотреть, как аналогичные продукты монетизируются.
- Выбрать устойчивый технический стек для сценариев на базе языковой модели и парсинга резюме.

## 2) Аналоги: эзотерика, гороскопы, таро
- Solomon Astrology Bot — https://solomonastro.com/
- Stellium (AI Astrology Telegram Bot) — https://stellium.app/
- «Астролог в кармане» — https://astrologbot.com/
- @horoscopebot (Horoscope Bot) — https://telegram.me/horoscopebot
- @divastro_bot (DIVAstro) — https://www.telegrambots.info/bots/divastro_bot
- @starsxspellsbot (AI Tarot + Horoscopes) — https://www.findmini.app/starsxspellsbot/

### Вывод по сегменту
- На рынке востребованы короткие эмоциональные сценарии: прогнозы, совместимость, ритуалы, таро.
- Большинство решений ограничиваются 1-2 магическими функциями и редко объединяют развлечение с прикладным сценарием для HR.
- Для минимально жизнеспособного продукта это подтвердило идею смешанного позиционирования: развлекательное ядро и прикладной HR-модуль как отличительный элемент.

## 3) Аналоги: монетизация Telegram-ботов и каналов
- MyMembers — https://mymembers.io/
- SimpleSub — https://simplesub.io/
- BotSubscription — https://botsubscription.com/
- Telesub — https://www.telesub.app/

### Вывод по монетизации
- Наиболее типовые модели: подписка, оплата за отдельный запуск, премиум-доступ и витрина тарифов.
- В проекте реализована упрощённая версия этих механизмов: баланс, цены, премиум, подписка, но сама оплата оставлена в режиме симуляции.

## 4) Официальные источники Telegram
- Bot Payments (Stars, XTR) — https://core.telegram.org/bots/payments-stars
- Telegram Stars API — https://core.telegram.org/api/stars
- Star Subscriptions API — https://core.telegram.org/api/subscriptions

### Как это повлияло на проект
- Материалы использовались как ориентир для проектирования платежного и подписочного контура.
- В итоговой версии сохранена логика цен и подписок, но реальные платежные интеграции не подключались, чтобы не перегружать базовое решение.

## 5) Примеры использования Ollama в Telegram
- ollama-telegram (GitHub) — https://github.com/rikkichy/ollama-telegram
- ollama-bot (GitHub) — https://github.com/Mateodioev/ollama-bot

### Вывод по интеграции языковой модели
- Готовые примеры подтвердили жизнеспособность схемы `Telegram -> HTTP -> Ollama`.
- Для проекта был выбран локальный или сетевой запуск `Ollama`, чтобы сохранить контроль над моделью и не зависеть от внешнего облачного сервиса.

## 6) Парсинг резюме и документов
- python-docx (DOCX) — https://python-docx.readthedocs.io/en/develop/
- pypdf (PDF) — https://pypdf.readthedocs.io/
- pyresume (GitHub) — https://github.com/wespiper/pyresume

### Вывод по HR-модулю
- Для минимально жизнеспособного продукта критично было поддержать `docx|pdf|md`, потому что это самые типовые форматы резюме.
- Источники использовались как практические референсы для извлечения текста и проектирования собственного лёгкого парсера на регулярных правилах.

## 7) Как именно источники использованы в проекте
- Аналоги из разделов 2-3 помогли сформировать состав минимально жизнеспособного продукта: гороскопы, совместимость, подписка, витрина цен, премиум.
- Официальная документация Telegram определила направление для проектирования экономики бота.
- Примеры с `Ollama` легли в основу интеграции генерации текста и сценариев анализа изображений.
- Источники по парсингу документов легли в основу HR-функции загрузки резюме.

## 8) Ограничения обзора
- Обзор носит прикладной продуктовый характер и не претендует на полноценное академическое исследование.
- Для части аналогов анализировались открытые лендинги, каталоги ботов и доступные публичные описания.
