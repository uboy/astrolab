# Архитектура проекта

## Компоненты высокого уровня
- **Точка входа**: Инициализирует бота, регистрирует роутеры и запускает планировщик подписок в фоновом режиме. См. `main.py:main`.
- **Обработчики (Handlers)**: Реализуют логику функций: гороскоп, совместимость, нумерология, предсказание по фото, викторина, снятие порчи, подписки, админка и платежи. См. `handlers/*.py`.
- **Утилиты (Utils)**: Обеспечивают конфигурацию, хранение данных, лимиты, интеграцию с Ollama и вспомогательные функции для сообщений. См. модули в `utils/`.
- **Клавиатуры (Keyboards)**: Генерируют главное меню и меню оплаты с динамическими ценами. См. `keyboards/menus.py:menu_for`.

## Модели данных
- **Запись пользователя**: Хранится в `data/users.json`, содержит баланс (`free_count`, `paid_count`), историю, действия, лимиты, данные подписки и профиль.
- **Подписки**: Содержат статус активности, время отправки и дату последнего сообщения.
- **Цены**: Хранятся в `data/prices.json`, значения по умолчанию берутся из констант.
- **Статистика Ollama**: Логи времени выполнения запросов для каждой модели.

## Потоки управления
- **Запрос пользователя**: Сообщение -> роутер aiogram -> валидация в обработчике -> проверка баланса и лимитов -> списание средств -> вызов Ollama -> форматирование ответа -> отправка в Telegram.
- **Платежный поток**: Выбор суммы и метода -> симуляция задержки -> случайный результат (успех/ошибка) -> обновление баланса.
- **Планировщик подписок**: Запускается каждые 60 секунд -> обходит активных подписчиков -> проверяет время отправки -> генерирует и отправляет гороскоп -> списывает оплату.

## Интеграции
- **Telegram Bot API**: Через библиотеку `aiogram`.
- **Ollama HTTP API**: Через `httpx`, используется для генерации текстов и анализа изображений.
- **Pydantic Settings**: Управление конфигурацией через переменные окружения.
- **Файловая система**: JSON-хранилища для персистентности данных.
