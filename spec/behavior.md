# Поведение и сценарии

## Основные пользовательские сценарии

### 1. Первое знакомство
- Пользователь отправляет `/start`.
- Бот регистрирует нового пользователя с бесплатными лимитами.
- Бот отображает приветственное сообщение и главное меню.

### 2. Запрос предсказания (на примере Гороскопа)
- Пользователь нажимает «Гороскоп».
- Бот запрашивает дату рождения.
- Бот проверяет баланс (бесплатный или платный).
- Бот отправляет запрос в Ollama, отображая анимацию ожидания.
- Результат выводится пользователю вместе с остатком баланса.

### 3. Анализ кандидата (HR-модуль)
- Пользователь выбирает «Проверка кандидата».
- Бот предлагает ввести данные вручную или загрузить файл резюме.
- При загрузке файла (`docx`, `pdf`, `md`) бот извлекает текст.
- Бот сопоставляет данные с параметрами компании и выдает шуточный вердикт.

### 4. Подписка
- Пользователь выбирает «Подписка».
- Бот предлагает оформить ежедневную рассылку.
- После активации бот ежедневно присылает персональный гороскоп в заданное или автоматически рассчитанное время.

### 5. Пополнение баланса
- Пользователь выбирает «Пополнить».
- Выбирает сумму и способ оплаты (симуляция).
- После подтверждения баланс `paid_count` увеличивается.

## Администрирование
- Админы (указанные в `.env`) имеют доступ к меню «Админка».
- Функции: просмотр списка пользователей, изменение баланса, редактирование цен, массовая рассылка, настройка параметров компании.
