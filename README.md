# Astrolab Bot

Курсовой проект по треку «Быстрое создание MVP в Data Science».

`Astrolab Bot` — Telegram-бот на `aiogram`, который сочетает развлекательные сценарии на базе языковой модели и прикладной HR-модуль. Бот использует локальную или доступную по сети `Ollama`-модель для генерации текстов и анализа изображений, поддерживает базовую монетизацию, подписки и административное управление.

## Что умеет бот

### Пользовательские сценарии
- Гороскоп по дате рождения.
- Нумерология по имени и дате рождения.
- Проверка совместимости по именам.
- Проверка совместимости по фотографиям.
- Фото-анализ в формате «судьба по фото».
- Игровые сценарии: угадывание знака зодиака и «перезапуск удачи».
- Пополнение баланса в режиме симуляции.
- Подписка на ежедневный гороскоп.
- Премиум-режим с изменёнными лимитами.
- HR-модуль: загрузка резюме `docx|pdf|md` или текста и оценка совместимости кандидата с компанией.

### Возможности для администратора
- Просмотр пользователей и их баланса.
- Изменение цен на функции.
- Управление подписками.
- Редактирование параметров компании для HR-модуля.
- Служебные действия по сопровождению пользователей.

## Для кого проект
- Пользователи Telegram, которым нужны быстрые развлекательные сценарии с атмосферной подачей.
- HR-специалисты и малые команды, которым нужен лёгкий демонстрационный инструмент для экспресс-оценки резюме.

Подробный анализ аудитории вынесен в [ANALYSIS.md](ANALYSIS.md).

## Архитектура и технологии
- `Python 3.11+`
- `aiogram 3`
- `httpx`
- `Pydantic Settings`
- `Ollama` для генерации текста и анализа изображений
- Файловое JSON-хранилище вместо БД

Структура проекта:
- `main.py` — точка входа и запуск роутеров.
- `handlers/` — пользовательские и административные сценарии.
- `utils/` — конфигурация, интеграции, парсинг, хранение, лимиты, логирование.
- `keyboards/` — меню и кнопки.
- `data/` — рабочие JSON-данные и статические ресурсы.
- `tests/` — автотесты для критических путей.
- `spec/` — описание архитектуры, поведения, запуска и качества.

## Хранение данных
- `data/users.json` — баланс, история, действия, профиль, лимиты, подписки.
- `data/prices.json` — цены функций.
- `data/company_params.json` — параметры компании для HR-анализа.
- `data/ollama_stats.json` — статистика времени ответов модели.

## Быстрый запуск

### Локально
1. Создать виртуальное окружение:
   ```powershell
   python -m venv .venv
   .venv\Scripts\activate
   ```
2. Установить зависимости:
   ```powershell
   pip install -r requirements.txt
   ```
3. Создать `.env` и заполнить минимум:
   ```env
   BOT_TOKEN=telegram-bot-token
   OLLAMA_URL=http://host.docker.internal:11434/api/generate
   OLLAMA_MODEL=llama3
   RATE_LIMIT_PER_MIN=5
   RATE_LIMIT_PER_HOUR=50
   FREE_MESSAGES_COUNT=4
   ADMINS=123456789,987654321
   ```
4. Запустить Ollama и модель.
5. Запустить бота:
   ```powershell
   python main.py
   ```

### Через Docker
```powershell
$env:BOT_VERSION = (git rev-parse HEAD)
docker compose build bot
docker compose up -d bot
```

Если `BOT_VERSION` не задан, контейнер попытается определить версию из `.git`.

## Проверка качества
- Автотесты запускаются командой:
  ```powershell
  python -m pytest
  ```
- На дату актуализации документа автотесты покрывают маршрутизацию кнопок, разбор резюме и граничные случаи по форматам и полям.
