# AI Chat Bot Product

Telegram-бот на aiogram, который общается с Ollama и предлагает магические предсказания, анализ и оплату внутри чата.

## Возможности для пользователей
- Гороскоп по дате рождения.
- Нумерология по имени и дате рождения.
- Проверка совместимости по двум именам.
- Анализ фото (vision модель Ollama).
- Снятие порчи (текстовый запрос + готовые сценарии).
- Определение наличия проклятия (игровой сценарий без списания лимита).
- Пополнение баланса (эмуляция оплаты).

## Возможности для администраторов
- Команда `Админка` → просмотр статистики по пользователям (баланс, обращения, первое появление, последняя активность).
- Сброс лимитов всех пользователей до значений по умолчанию.
- Доступ контролируется списком `ADMINS` из `.env`.

## Хранение данных
- Файл `data/users.json` (создаётся автоматически):
  - `free_count`, `paid_count` — баланс обращений.
  - `first_seen`, `last_seen` — первое подключение и последняя активность.
  - `history` — список временных меток обращений.
  - `actions` — подробные события с названием функции и параметрами (например, дата рождения, имена, выбранный ритуал, данные об оплате).
  - `profile` — сохранённые поля Telegram-пользователя (id, username, имя, язык, premium и т.д.).
  - `rate`, `state` — служебные поля для антиспама/состояний.

## Настройки (.env)
Создайте файл `.env` в корне:
```
BOT_TOKEN=telegram-bot-token
OLLAMA_URL=http://host.docker.internal:11434/api/generate
OLLAMA_MODEL=llama3
RATE_LIMIT_PER_MIN=5
RATE_LIMIT_PER_HOUR=50
FREE_MESSAGES_COUNT=4
ADMINS=123456789,987654321
```
- Для Docker на Windows/Mac используйте `host.docker.internal` для доступа к локальному Ollama.
- `ADMINS` — список ID через запятую.

## Локальный запуск
1) Python 3.11+.  
2) `python -m venv .venv && .venv\Scripts\activate`  
3) `pip install -r requirements.txt`  
4) Запустите Ollama/модель, затем `python main.py`.

## Запуск в Docker
```
docker build -t ai-chat-bot .
docker run --env-file .env -v %cd%\data:/app/data ai-chat-bot
```
- `--env-file .env` передаёт токены/настройки.
- Монтирование `data` сохраняет статистику пользователей вне контейнера.
- Убедитесь, что `OLLAMA_URL` доступен из контейнера (например, `http://host.docker.internal:11434/api/generate`).

## Структура
- `main.py` — точка входа, регистрирует все роутеры.
- `handlers/` — логика команд/кнопок.
- `utils/` — интеграция с Ollama, хранение данных, логирование, ограничения.
- `keyboards/`, `data/` — меню и статические файлы.
