# AI Architecture Guide

Этот файл — краткая навигация для AI-агентов: что это за проект, как устроен, какие ограничения и как добавлять новые фичи.

## О проекте

Telegram-бот на aiogram с «магическим» стилем ответов. Основные фичи: гороскоп, нумерология, совместимость, фото-анализ, проверки «проклятий», проверки кандидатов на совместимость с компанией. Платные/бесплатные лимиты и логирование действий пользователей.

## Архитектурные блоки

- `main.py` — точка входа, регистрация роутеров.
- `handlers/` — все пользовательские и админские флоу (FSM).
- `utils/` — бизнес-логика, парсеры, интеграции, хранение, лимиты, логирование.
- `keyboards/` — кнопки/меню.
- `data/` — JSON-хранилища.

## Данные и хранилища

- `data/users.json` — пользователи, лимиты, история, лог действий.
- `data/prices.json` — цены фич.
- `data/company_params.json` — параметры компании (сырой текст).

## Лимиты и списания

- Используйте `utils.pricing_helpers.ensure_balance_and_charge(...)` для списания и логирования.
- Проверка rate limit через `utils.rate_limit.check_rate_limit(...)`.
- Логирование действий: `utils.user_helpers.decrement_user_limit` пишет `actions` и `history`.

## Интеграции

- Ollama: `utils/ollama.py` + `utils/prompts.py`.
- Внешние файлы резюме: `utils/resume_ingest.py` + `utils/resume_parser.py`.

## Ограничения и рекомендации

- Не логировать персональные данные в `actions` (PII).
- Все пользовательские ответы — в лёгком шуточном стиле, но без дискриминации.
- Проверять корректность форматов входных данных (файлы, возраст, даты).
- Не использовать синхронный I/O в горячих обработчиках (FSM) без необходимости.

## Как добавлять новую фичу (шаблон)

1) **Константы**
   - Добавить кнопку, тексты, цены в `utils/constants.py`.
2) **Меню**
   - Обновить `keyboards/menus.py`.
3) **Handler**
   - Создать новый файл в `handlers/`, описать FSM и флоу.
   - Использовать `ensure_balance_and_charge`, `check_rate_limit`.
4) **Бизнес-логика**
   - Вынести обработку в `utils/` (парсер/скоринг/генерация).
5) **Хранилища**
   - Если нужны новые данные — использовать `utils/json_db.py`.
6) **Регистрация**
   - Подключить роутер в `main.py`.
7) **Тесты**
   - Добавить pytest-coverage на ключевые сценарии.

## Стиль ответов

- Дружелюбный юмор, без оскорблений.
- Итог + краткие причины + сжатое резюме (если применимо).

## Фича: Проверка кандидата

- Handler: `handlers/candidate_compatibility.py`
- Парсинг резюме: `utils/resume_ingest.py`, `utils/resume_parser.py`
- Параметры компании: `utils/company_params.py`
- Логика совместимости: `utils/candidate_compatibility.py`
- Админ-редактор параметров: `handlers/admin.py`
